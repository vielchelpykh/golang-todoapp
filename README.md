## Реализованный функционал

На данный момент реализованы следующие эндпоинты для управления пользователями:

| Метод    | Путь              | Описание                                      |
| :---- ---| :---------------- | :-------------------------------------------- |
| `POST`   | `/api/users`      | Создание нового пользователя                  |
| `GET`    | `/api/users`      | Получение списка пользователей (с пагинацией) |
| `GET`    | `/api/users/{id}` | Получение пользователя по ID                  |
| `PATCH`  | `/api/users/{id}` | Частичное обновление пользователя             |
| `DELETE` | `/api/users/{id}` | Удаление пользователя                         |

В планах: реализация CRUD для задач (tasks) и статистики.

## Стек технологий

- **Go** (`net/http`, `gorilla/mux`, `pgx`)
- **PostgreSQL** (миграции, CRUD операции, оптимистичные блокировки)
- **Docker** и **Docker Compose**
- **Makefile** для автоматизации
- **Чистая архитектура** (слои: транспорт → сервис → репозиторий)
- Переменные окружения (`.env`)

---

## Архитектура

Проект построен по принципам **чистой архитектуры**:

1.  **Transport** — HTTP-обработчики, валидация запросов.
2.  **Service** — бизнес-логика, обработка данных.
3.  **Repository** — работа с PostgreSQL (CRUD, миграции).
